Regla Clave

Los cazadores solo caminan por espacio libre (costo 1). El dron puede volar por niebla, montanas y tormentas gastando mas bateria. Esto le da ventaja para escapar.

El Juego por Turnos

1
El dron elige una accion (arriba, abajo, izquierda, derecha o quedarse)
2
Cada cazador elige una accion (en orden: cazador 1, cazador 2, etc.)
3
Se verifica: ¿Algun cazador esta en la misma casilla que el dron? → DERROTA
4
Se verifica: ¿El dron ya visito todos los puntos de entrega? → VICTORIA

Repaso: Minimax

Minimax es lo que tus compañeros implementaron en el Punto 2. Necesitas entenderlo para hacer Expectimax.

La Idea Central

El dron (MAX) quiere maximizar su puntaje.

Los cazadores (MIN) quieren minimizar el puntaje del dron.

Minimax asume que los cazadores siempre juegan perfecto (peor caso para el dron).

El Problema de Minimax

Minimax asume que el cazador SIEMPRE elige la accion optima (peor para el dron).

Pero en la realidad, los cazadores a veces:

  • Se mueven al azar (no ven al dron)
  • Se equivocan de direccion
  • No tienen informacion perfecta

Resultado: El dron es DEMASIADO conservador y pierde oportunidades.

A veces greedy, a veces aleatorio

Realista

La Formula del Nodo CHANCE

valor = (1 - p) × min(hijos) + p × promedio(hijos)

¿Que significa cada parte?

ParteSignificado
(1 - p) Probabilidad de que el cazador actue greedy (persigue al dron)
min(hijos) El peor valor para el dron (lo que elegiria un cazador greedy)
p Probabilidad de que el cazador actue al azar
promedio(hijos) Valor esperado si el cazador elige uniformemente al azar

    Como Implementarlo

    Pseudocodigo del ExpectimaxAgent

    def get_action(self, state): # Para cada accion legal del dron, calcula el valor expectimax best_action = None best_value = -infinito for action in state.get_legal_actions(0): # agente 0 = dron successor = state.generate_successor(0, action) value = expectimax(successor, depth=self.depth, agent=1) if value > best_value: best_value = value best_action = action return best_action def expectimax(state, depth, agent_index): # Caso base: estado terminal o profundidad 0 if depth == 0 or state.is_win() or state.is_lose(): return self.evaluation_function(state) num_agents = state.get_num_agents() next_agent = (agent_index + 1) % num_agents # Si el siguiente ciclo vuelve al dron (agent 0), reducimos depth next_depth = depth - 1 if next_agent == 0 else depth if agent_index == 0: # === NODO MAX (Dron) === max_value = -infinito for action in state.get_legal_actions(0): successor = state.generate_successor(0, action) value = expectimax(successor, next_depth, next_agent) max_value = max(max_value, value) return max_value else: # === NODO CHANCE (Cazador) === child_values = [] for action in state.get_legal_actions(agent_index): successor = state.generate_successor(agent_index, action) value = expectimax(successor, next_depth, next_agent) child_values.append(value) # Formula mixta: p = self.prob min_val = min(child_values) avg_val = sum(child_values) / len(child_values) return (1 - p) * min_val + p * avg_val

    Flujo de Ejecucion

    1
    get_action(state) se llama con el estado actual del juego
    2
    Para cada accion legal del dron, genera un sucesor y calcula su valor
    3
    Los cazadores (CHANCE) calculan: (1-p)*min + p*mean
    4
    Al llegar a profundidad 0 o estado terminal, se llama evaluation_function
    5
    Los valores burbujean hacia arriba y el dron elige la accion con mayor valor

    1. Complejidad de Minimax

    Complejidad en Tiempo

    O(bd)

    b = factor de ramificacion (acciones legales por agente, tipicamente 4-5)

    d = profundidad del arbol

    Con k cazadores, cada "turno completo" tiene (1+k) capas, asi que el arbol real es O(bd·(1+k))

    Complejidad en Espacio

    O(b · d)

    Solo almacena el camino actual en el arbol (busqueda en profundidad)

    En cada nivel hay como maximo b sucesores

    2. ¿Por que Minimax es pesimista?

    Imagina un cazador con p = 0.5 (50% aleatorio). El cazador tiene 4 movimientos posibles:

    AccionResultado para el dron
    ← (hacia el dron)-50 (peligroso)
    → (lejos del dron)+30 (seguro)
    ↑+10
    ↓+20

    Minimax dice:

    min(-50, 30, 10, 20) = -50

    "El cazador VA a ir hacia mi. Huir."

    Expectimax (p=0.5) dice:

    0.5 × min(-50,30,10,20) + 0.5 × mean(-50,30,10,20)

    = 0.5 × (-50) + 0.5 × (2.5) = -23.75

    "Hay riesgo, pero no tanto. Puedo intentar la entrega."

    Minimax pierde oportunidades porque asume lo peor. Expectimax toma riesgos calculados que en promedio le dan mejor resultado cuando el cazador no es perfecto.
